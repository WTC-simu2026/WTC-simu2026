To the General Counsel / FOI Administrator:

Under the Port Authority Public Records Access Policy, I request electronic copies of existing Port Authority records limited to the four World Trade Center 1 / North Tower / Tower A drawing sheets **A-A-148, A-A-150, A-A-151, A-A-153**, plus only the directly associated records needed to identify their version, source, custody and release history.

This is not a request for every World Trade Center drawing or for WTC 7 drawings. It does not seek all architectural or engineering records for the World Trade Center complex.

For each target sheet, please provide the following existing records, if held:

1. **R01 - native_or_original_digital_files**: Native CAD/DWG/DXF files or original digital image files actually held for each target sheet. Preferred delivery: Existing native format with original filename and extension.
2. **R02 - highest_resolution_raster_fallback**: Highest-resolution scan or raster actually held for each target sheet if no native file is held. Preferred delivery: Existing lossless or source raster format.
3. **R03 - sheet_identity_and_title_block**: Existing records preserving the complete sheet number, title, issue date and title block for each target sheet. Preferred delivery: Electronic copy of existing record.
4. **R04 - revision_and_issue_history**: Revision blocks, revision descriptions, supersession records and issue histories for each target sheet. Preferred delivery: Electronic copy of existing record.
5. **R05 - drawing_register_or_index**: The smallest drawing register, index or file listing that identifies the four target sheets and their revisions. Preferred delivery: Existing spreadsheet, database export, PDF or image.
6. **R06 - transmittal_inventory_or_accession**: Transmittal, accession, receipt, inventory, box, reel, disk or media records specifically identifying any target sheet or target digital file. Preferred delivery: Electronic copy of existing record.
7. **R07 - release_or_disclosure_history**: Existing release, disclosure, FOIA, public-records or transfer records specifically identifying one or more target sheets. Preferred delivery: Electronic copy of existing record.
8. **R08 - existing_file_metadata**: Existing file metadata for each held target file, including filename, size, pixel dimensions, resolution, bit depth, color mode, compression, checksum and creation/modification timestamps when recorded. Preferred delivery: Existing metadata export, inventory or sidecar.
9. **R09 - prior_or_subsequent_versions**: Any prior or superseding version of a target sheet that is separately held and identifiable by date or revision. Preferred delivery: Existing native or highest-resolution electronic copy.
10. **R10 - field_record_or_as_built_certification_if_any**: Any existing certification, stamp, transmittal or index entry specifically stating that a target version is field-verified, record-drawing or as-built; no such status is presumed. Preferred delivery: Electronic copy of existing record.
11. **R11 - disposition_or_referral**: If a target record is not held, the existing record of transfer, destruction, retention disposition, referral, withholding or responsible custodian, to the extent recorded and releasable. Preferred delivery: Existing disposition record or written record-status response.
12. **R12 - identifier_key**: The smallest existing legend or identifier key needed to interpret accession, database, media or drawing-register identifiers attached to the target records. Preferred delivery: Electronic copy of existing legend or key.

For this request, "native file" means the source CAD or original digital image file the Port Authority actually holds. I am not asking the Port Authority to create a new record, recreate a drawing, perform a forensic analysis, calculate new metadata, or convert a record into a format it does not hold. If no native file is held, please provide the highest-resolution scan or image version the Port Authority actually holds.

To keep the request detailed and not overly broad, a register, index, transmittal or database export may be limited to rows or portions that identify one or more of the four target sheets, together with the smallest existing legend needed to interpret their identifiers. If a target record was transferred to NIST or another custodian, please provide any existing releasable transmittal, accession, disposition or referral record that specifically identifies the target sheet or file.

Please provide records electronically in their existing formats when practicable, preserving original filenames. If only part of a responsive record is available, please provide the releasable portion. If a target record is not held, please state that status and, if recorded, identify any transfer, retention disposition or responsible custodian.

Please advise me of any estimated fee before a charge is incurred. This request contains no advance authorization for any fee amount and makes no legal claim beyond requesting records under the Port Authority's published access process.
